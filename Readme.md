# 🚀 Subscription Management System

> A smart web-based platform to manage, track, and monitor subscriptions from a single dashboard.

## 📌 About the Project

Subscription Management System is a web application designed to help users organize and manage their subscriptions efficiently. It provides a centralized platform to track subscription details, monitor payment schedules, manage expenses, and avoid missing renewal dates.

Developed as a hackathon project.

## ✨ Key Features

- User registration and login
- Subscription management (Add, View, Update, Delete)
- Track subscription costs and billing cycles
- Monitor upcoming renewal dates
- Manage active and expired subscriptions
- Dashboard with subscription insights
- Responsive user interface

## ⚙️ Installation & Setup

### 1. Clone the Repository

```bash
git clone YOUR_REPOSITORY_URL
cd subscription-management-system
```

### 2. Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

### 3. Backend Setup

Refer to the backend setup instructions provided in the `backend` directory.

### 4. Database Setup

- Create the required database.
- Import `schema.sql`.
- Import `seed.sql` if available.
- Configure database credentials in your local environment file.

### 5. Run the Application

Start the backend and frontend services.

Open the frontend URL in your browser.

## 🔐 Environment Configuration

Create a `.env` file using the provided `.env.example`.
