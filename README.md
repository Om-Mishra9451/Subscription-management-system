# SubscriptIQ
### Autonomous Revenue Assurance for Odoo
**Tagline: Detect. Prevent. Recover. Measure.**

---

## Executive Summary

**SubscriptIQ** is an autonomous revenue assurance engine built for **Brightloop Software** that integrates natively into **Odoo**. It operates across the complete subscription-to-cash lifecycle to detect financial leakage, prevent duplicate billing, orchestrate intelligent payment reconciliation, and measure verified recovered revenue with mathematical precision.

> **Core Axiom:** *Odoo manages the subscription business. SubscriptIQ protects the revenue generated by that business.*

---

## Core Product Capabilities

| Pillar | Operational Mechanism | Financial Outcome |
| :--- | :--- | :--- |
| **1. Revenue Guardian** | Continuous background scanner inspecting invoices, subscriptions, and payment attempts using deterministic business rules. | Eliminates silent revenue leakage; flags overdue debt and renewal exposure. |
| **2. Billing Protection Guard** | Transactional database reservation locks (`subscriptiq.billing.guard`) per subscription period. | Stops duplicate billing attempts at transaction time before invoice creation. |
| **3. Smart Reconciliation** | Multi-signal deterministic matching (0.50 ref, 0.30 amount, 0.15 partner, 0.05 date) on imported bank CSVs. | Recovers unmatched cash; updates accounting residuals via native `account.payment`. |
| **4. Verified Revenue Measurement** | Strict `Decimal` arithmetic calculating MRR, ARR, Revenue at Risk, and Verified Recovered Revenue. | Zero floating-point drift; counts only bank-reconciled allocations. |
| **5. AI Finance Copilot** | Free-tier LLM integration (Groq → Gemini → OpenRouter) with tool whitelisting and two-phase proposals. | Grounded natural language queries without arbitrary SQL execution risks. |
| **6. Compliance & Audit Trail** | Cryptographic SHA-256 tamper-evident hash chaining on all critical operations. | Append-only ledger providing verifiable proof of who changed what, when, and why. |
